# atrium static demo

Source: https://github.com/temirlanzzz/atrium

Source commit: b3a54e66655b022cab146badc87aa1ab8c8f4a02

Built with Node.js v22.22.0: npm ci, then npm run build (Vite, relative base).

Reproduce from the portfolio root: node tools/sync-three-demo.mjs atrium ../atrium

Everything is procedural; no third-party textures, models or fonts are bundled.
