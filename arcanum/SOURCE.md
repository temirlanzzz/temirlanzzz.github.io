# arcanum static demo

Source: https://github.com/temirlanzzz/arcanum

Source commit: fa58aba3e4955804c14e1856b525af3f532792bf

Built with Node.js v22.22.0: npm ci, then npm run build (Vite, relative base).

Reproduce from the portfolio root: node tools/sync-three-demo.mjs arcanum ../arcanum

Everything is procedural; no third-party textures, models or fonts are bundled.
